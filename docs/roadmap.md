# 路线图

按顺序做，一次一个主题。新想法先开 issue，不插进正在做的主题。

## 0.1 仓库基线（已完成）

MyGo 模板初始化、MIT 许可、开源社区文件、CI。产品规格 [product.md](product.md) 和架构决定 [ADR 0001–0004](adr/README.md)。窗口里还是模板的计数示例。

## 之后

候选，开工前再排顺序。没有界面的核心逻辑先做，每一步都有无头测试：

1. **账户和生成配置**：`accounts.json` 读写和备份、生成托管文件、插入和移除 Include 标记块。没有界面，只有测试。
2. **托盘和面板**：托盘图标、点开的面板、身份列表、拖入文件夹后的匹配结果卡片。
3. **绑定**：把文件夹绑定到账户、解绑、改绑、撤销，旧路径失效后改指向，多个账户覆盖同一目录时的说明。
4. **账户窗口**：新建、编辑、删除账户，设置页，备份和恢复。
5. **连通性检查和诊断**：`ssh -T` 检查、失败分类和下一步操作、诊断汇总。
6. **密钥**：生成密钥、加载到 ssh-agent、复制公钥。
7. **导入**：从已有的 `~/.ssh/config` 和 `~/.gitconfig` 导入账户。
8. **签名、公证、自动更新和发布**。

## 发布前

产品图标、签名证书、更新源和公钥都配好，并在三个平台的真机上验收安装、托盘、拖放和更新。
