# 路线图

按顺序做，一次一个主题。新想法先开 issue，不插进正在做的主题。

## 0.1 仓库基线（已完成）

用 MyGo 搭好项目、MIT 许可、开源社区文件、CI。产品规格 [product.md](product.md) 和架构决定 [ADR 0001–0004](adr/README.md)。窗口里还是一个计数示例。

## 0.2 身份数据和生成配置（已完成）

`accounts.json` 读写、校验和备份，生成托管文件，插入和移除 Include 标记块。没有界面，有调用真实 `git` 的测试。

## 0.3 托盘和面板（已完成）

托盘图标、面板、身份列表和筛选，拖入或选择文件夹后的匹配结果卡片。只开一个实例。

## 之后

候选，开工前再排顺序，每一步都有无头测试：

1. **绑定和克隆助手**：把文件夹绑定到身份、解绑、改绑、撤销，旧路径失效后改指向，多个身份覆盖同一目录时的说明，克隆助手和改地址命令。
2. **账户窗口**：新建、编辑、删除账户，设置页，备份和恢复。
3. **连通性检查和诊断**：`ssh -T` 检查、失败分类和下一步操作、诊断汇总。
4. **密钥**：生成密钥、加载到 ssh-agent、复制公钥。
5. **导入**：从已有的 `~/.ssh/config` 和 `~/.gitconfig` 导入账户。
6. **签名、公证、自动更新和发布**。

## 发布前

产品图标、签名证书、更新源和公钥都配好，并在三个平台的真机上验收安装、托盘、拖放和更新。
