# 设计系统

## 原则

用 MyGo 的原生控件和主题默认值，跟随系统的浅色、深色和强调色。含义用文字表达，不只靠颜色：每个身份的颜色点旁边都有名称，结果卡片的状态写成一句话。没有自定义动画，状态变化立即生效。

每个界面先在 `design/` 画板和本文件里写清规格，再写代码；界面以 `design/` 和本文件为准。

## 颜色

只用 MyGo 主题色，画板里的颜色是近似值，以真机效果为准：

| 用途 | 主题色 |
|---|---|
| 面板底色 | `Background` |
| 卡片、身份列表、输入框、按钮底色 | `Surface` |
| 分隔线、卡片和列表边框、拖放区虚线 | `Border` |
| 次要文字、提示 | `TextMuted` |
| 拖着文件经过拖放区、选中的平台筛选 | `Accent`，文字 `AccentText` |
| 「没有匹配」「不是 Git 仓库」「不是文件夹」卡片的边框 | `Warning` |
| 符号按钮悬停时的底色 | `SurfaceHover` |
| 运行不了 `git` 的边框和文字；`accounts.json` 读不出来时的警示图标（底色是它的 14% 不透明度） | `Danger` |

身份颜色：六个预设名对应固定的色值（blue `#3A7BD5`、green `#2E9E5B`、orange `#E07A1F`、red `#D64545`、purple `#8E44AD`、yellow `#D4A017`），其余用 `#RRGGBB` 本身。身份颜色只用在首字母徽章上：底色是身份颜色的 16% 不透明度（深色 24%），字母是身份颜色本身（深色时向白色混合 40%，保证对比度）。

## 字体

系统字体。字号：面板标题 15 粗体；结果卡片里的身份名 15 半粗；列表里的身份名用默认字号半粗；次要说明、分组标题 12；路径、别名、生效目录用等宽字体 12（列表右侧的生效目录 11）。一张卡片里不超过三种文字样式。

## 布局和间距

- 面板固定 340×480，无边框，不能调整大小。标题栏和底栏内边距 12×16，和内容之间有分隔线。
- 内容区外边距 16，块之间间距 12。有身份列表时可滚动；读取中、读不出来、没有身份时不滚动，内容可以上下居中。
- 卡片、身份列表和拖放区圆角 10；拖放区为空闲状态时内边距 20×16，居中排列。
- 结果卡片分两段，中间一条分隔线：上段是路径行，内边距 8（左 12）；下段是结论，内边距 12。
- 已匹配的结论：36 的首字母徽章（圆角 9）和身份名、「Git 在这里用这个身份」，间距 12；下面是「别名」「邮箱」「生效目录」三行，标签宽 56，和身份名左对齐（左内边距 60）。
- 身份列表：分组标题「身份」和数量在上面，列表是一个容器，行之间一条分隔线。每行内边距 9×12：28 的首字母徽章（圆角 7）、间距 10、身份名和邮箱两行、右边是生效目录（第一条，多条时加「+N」；全局写「全局」）。不截断文字。
- 卡片里的符号按钮 24×24，无边框。

## 组件

| 组件 | 用法 |
|---|---|
| `ui.Button` | 次要操作。只有符号的按钮必须用 `.Label()` 给出可读名称。 |
| `ui.PrimaryButton` | 一组按钮里的主操作，最多一个。面板里没有主操作。 |
| `ui.Text` | 文字。次要说明用 `TextMuted`。 |
| `ui.TextInput` | 身份筛选，三个及以上身份时出现，占位文字「筛选身份」。不用 `ui.SearchField`：它的占位文字和清除按钮的名字固定是英文。 |
| `ui.Spinner` | 读取中。 |
| 拖放区 | `ui.Column`，`Border` 1.5 虚线（`BorderDashed`），用 `DroppedFiles` 接收文件，`FileDragOver` 时边框和底色换成强调色。 |
| 首字母徽章 | 圆角方块，身份名的第一个字（没有名字时是「?」），用身份颜色（见「颜色」）。 |
| 无边框符号按钮 | 24×24，透明底，图标 14，`TextMuted`，悬停用 `SurfaceHover` 底色。必须用 `.Label()` 给出名字。复制路径成功后图标换成对勾，前面出现「已复制」，1.2 秒后恢复。 |
| 结果卡片 | 上段路径行（等宽 `TextMuted`，右边是复制和清除按钮），下段结论。`Surface` 底色，`Border` 边框；没有匹配类用 `Warning`，`git` 失败用 `Danger`。 |
| 身份列表 | 分组标题加一个 `Surface` 容器，行之间用 `Border` 分隔线。 |
| 平台筛选 | 一排 `ui.Button`，选中的用 `Accent` 底色，读屏读作已选中。 |

## 面板

画板：[design/screens/panel.html](../design/screens/panel.html)。

从上到下：标题栏（「Idset」，没有关闭按钮：托盘图标和 Esc 负责隐藏）、内容区、底栏（「退出」）。内容区的顺序：

1. 读取中：只有转圈和「正在读取配置…」。
2. `accounts.json` 读不出来：这时别的都做不了，所以错误占满内容区并上下居中：44 的警示徽章（圆角 11）、标题（15 半粗）、一句说明、原因框（`Background` 底色、`Border` 边框、圆角 6，等宽 11 的文件路径和具体错误）、「在 Finder 中显示」（Windows 上是资源管理器，Linux 上是文件管理器）和「重新读取」两个按钮。
3. 其他情况：结果卡片（有结果时）→ 拖放区 → 分组标题「身份 N」→ 筛选（三个及以上身份时）→ 身份列表；没有身份时列表换成「还没有身份」和一句说明。

拖放区有两种样子：没有结果时是大块的虚线框，写「把项目文件夹拖到这里」「看看这个目录会用哪个身份推送」和「选择文件夹…」；有结果时缩成一行「拖入另一个文件夹，或」加「选择文件夹…」。

## 无障碍

按钮有名字，焦点顺序用标准行为。对比度、缩放、键盘和读屏在真机上验，无头测试通过不算数。Esc 隐藏面板。
