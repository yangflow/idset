# 0003 拖放区放在托盘弹出的窗口里

- 状态：已采纳
- 日期：2026-10-12
- 相关：[docs/product.md](../product.md)「拖入文件夹」、[ADR 0001](0001-pure-go-native-ui.md)

## 背景

最直接的手势是把项目文件夹拖到托盘图标上，看这个仓库会用哪个身份。MyGo v0.3.5 的托盘图标只有单击和右键两个事件，不接受拖放；只有窗口能接收文件拖放（`OnFileDrop`）。

## 决定

单击托盘图标，在图标下方打开一个无边框的小窗口（下称「面板」），失去焦点时隐藏，用法和 MyGo 的菜单栏示例一样。面板里有拖放区，文件夹拖进面板后进入匹配流程。拖放区在没有匹配结果时最显眼，有结果后缩成一行提示，结果卡片在下面。

## 代价

多一步：先点开面板，再拖进去。拖着文件夹时没法打开面板，所以要先点开。面板失去焦点就隐藏，这会和从 Finder、资源管理器拖文件的过程冲突，所以拖放进行中和拖入后都不隐藏，直到用户点别处。

## 什么时候重新考虑

MyGo 的托盘图标支持拖放。那时可以加上拖到图标上这个入口，面板里的拖放区保留。
